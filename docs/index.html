Core capabilities

从原始表格到可信决策

系统明确区分数据清洗、规则异常、后处理汇总与完整物理或预测模型，避免把趋势展示误读为预测结论。

01

质量门禁

检查必需列、日期与数值范围、班组变体、重复粒度、空记录和配对完整率；高等级问题必须确认后才能发布。

02

不可变版本

共享数据版本通过文件哈希、审计记录和单活动快照管理，支持安全发布、归档与回滚。

03

双粒度分析

在班次和炉日粒度之间切换，以配对记录计算加权产率，避免简单平均与缺失记录造成统计偏差。

04

炉号诊断

查看炉号排名、累计产量、加权产率、故障时间和趋势明细，支持产线、炉号和时间范围联动筛选。

05

规则异常

采用炉号内 σ 规则和最低产率阈值识别异常低产班次，并明确说明其为历史规则标记，而非未来故障概率。

06

离线报表

后台生成每日汇总等 Excel 报表，支持 SVG/PNG 图表导出；前端生产包无 CDN、无外网依赖。
