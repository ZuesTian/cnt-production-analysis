# 碳纳米管生产数据分析系统

碳纳米管（CNT）生产线数据综合分析工具，支持 **L3** 和 **11A** 产线的炉子级统计、每日/月汇总、异常检测、故障分析和故障预警。

## 功能一览

| 模块 | 说明 |
|------|------|
| 炉子级统计 | 每个炉子的反应周期明细、月度平均、每月前/后 20% 高低排名 |
| 每日汇总 | 全区 / 分线 的总产量、总反应时间、总故障时间、总空烧时间、总降清时间 |
| 每月汇总 | 同上按月聚合 |
| 单炉趋势 | 每个炉子单独的每日趋势图（含 7 日均线 + 线性回归趋势线 + 异常标记 + 故障标记） |
| 异常检测 | 3σ 原则 + 最低产率阈值，自动标记异常低产周期 |
| 故障分析 | 故障炉号排名、星期分布、热力图 |
| 故障预警 | 单日超阈值 / 连续故障 / 月累计超标 三级预警，分析完自动弹出预警窗口 |

## 快速开始

### 方式一：打包版（推荐，无需 Python）

1. 下载 `dist/碳纳米管生产数据分析.exe`
2. 将生产数据 `.xlsx` 文件放在 exe 同目录（会自动识别文件名含"生产数据"的文件）
3. 双击 exe 启动 GUI

### 方式二：源码运行

```bash
pip install -r requirements.txt
python gui_app.py
```

### 方式三：命令行

```bash
python analysis.py --all                          # 全部分析
python analysis.py --furnace E01 E02 --daily      # 指定炉子 + 每日汇总
python analysis.py --anomaly                      # 异常检测
python analysis.py --fault-analysis --fault-warning  # 故障分析 + 预警
python analysis.py --list-furnaces                # 列出所有炉号
```

## 使用教程

### 1. 启动与加载数据

打开软件后，界面左侧为控制面板，右侧为结果展示区。

- **数据源**：软件会自动识别目录中的 `.xlsx` 文件，也可点击「浏览」手动选择
- 点击「加载数据 / 刷新炉号」按钮，数据加载后顶部统计卡片会显示反应周期数、炉号数量、日期范围和生产线信息
- 炉号列表会列出所有可用炉子

### 2. 选择炉号范围

- **全区炉子**：分析所有炉子（默认）
- **自选炉子**：在列表中点击选中（支持 Ctrl/Shift 多选），或输入前缀（如 `E` 匹配所有 E 开头的炉号）

选好后可看到 "已选 X 个炉号" 的提示。

### 3. 勾选分析内容

勾选需要运行的分析项：

| 分析项 | 说明 |
|--------|------|
| 炉子级统计 | 反应周期明细 + 月度平均 + 前后 20% 筛选 |
| 每日汇总 | 全区每日总产量 + 各项时间统计 |
| 每月汇总 | 同上按月汇总 |
| 单炉每日趋势数据 | 每个炉子的单独趋势数据 |
| 低产率异常检测报告 | 3σ + 最低产率双阈值检测 |
| 故障分析 + 故障热力图 | 故障排名 + 星期分布 + 热力图 |
| 故障预警报告 | 三级预警（分析完自动弹出预警窗口） |

### 4. 运行分析与导出

- 点击 **「运行分析」**：所有勾选项的计算结果暂存内存，不写磁盘
- 输出文件列表会显示已缓存的数据项及条数
- 点击 **「导出报表」**：将缓存的分析结果一次性写入 Excel 文件到输出目录
- 点击 **「预览单炉趋势」**：选中炉子后实时生成并预览该炉的每日趋势图

### 5. 查看结果

#### 趋势图预览 Tab

- **每日趋势图 / 每月趋势图 / 故障热力图**：点击按钮预览全区汇总图
- **单炉趋势图下拉框**：选择炉子后查看其单独趋势图
- 预览图会随窗口大小自适应缩放

#### 输出文件 Tab

- 运行分析后显示缓存的数据摘要
- 导出报表后显示已生成的 Excel 文件列表
- 双击文件可直接打开

#### 故障预警窗口

- 启用故障预警后，分析完成自动弹出独立窗口
- 上半部分：预警汇总（按炉号统计预警次数）
- 下半部分：预警明细（按严重程度着色：红 = 严重，黄 = 预警）
- 可点击「打开 Excel 文件」查看完整报告

### 6. 配置文件

`config.yaml` 支持自定义设置，修改后可适配不同的数据格式：

```yaml
# 数据列映射（源表列名 → 内部名称）
source_columns:
  date: 日期
  furnace: 炉号
  reaction_time: 生产时间
  fault_time: 设备故障影响时间
  clean_empty_burn_time: 停机清理空烧
  output: 产量
  source_yield: 小时产能

# 产线识别规则
production_lines:
  L3:
    patterns: ["E", "F", "G", "H", "B"]
  "11A":
    patterns: ["11A"]

# 告警阈值
alert_thresholds:
  fault_warning_hours_per_day: 8     # 单日故障预警阈值
  fault_critical_hours_per_day: 12   # 单日故障严重阈值
  consecutive_fault_days: 2          # 连续故障天数阈值
  monthly_fault_hours_warning: 24    # 月累计故障阈值
  min_yield_rate: 50                 # 最低产率阈值
  anomaly_sigma: 2.0                 # 异常检测 σ 倍数
```

## 数据格式说明

输入 Excel 需包含以下列（列名可通过 config.yaml 自定义）：

| 列名 | 说明 | 示例 |
|------|------|------|
| 日期 | Excel 日期序列号或标准日期 | 46023 或 2026-01-01 |
| 班组 | 白班/夜班 | 白班 |
| 炉号 | 炉子编号 | E01, 11A17 |
| 生产时间 | 反应运行时间（小时） | 9.3 |
| 设备故障影响时间 | 故障停机时间（小时） | 2.5 |
| 停机清理空烧 | 空烧/降清时间（小时） | 1.0 |
| 产量 | 产量（kg） | 830 |
| 小时产能 | 产率（kg/h） | 89.2 |

> 注意：数据中「停机清理空烧」同时作为"空烧时间"和"降清时间"统计。如果后续源表拆分为两个独立字段，修改 `config.yaml` 即可。
